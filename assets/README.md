# Assets CREATIV GROUP

Pour utiliser le logo officiel exact de CREATIV GROUP dans l'interface et les exports,
déposer le fichier PNG validé ici sous le nom :

`assets/creativ_group_logo.png`

CGS utilisera automatiquement ce fichier dans l'interface, Excel, Word et PDF.
En son absence, un lockup sobre CREATIV GROUP / CGS est généré automatiquement afin
d'éviter toute dépendance réseau au démarrage.
