# Mise à jour V2.3 -> V2.4

Aucune nouvelle bibliothèque n'est nécessaire.

1. Fermer CADUCEUS et les fenêtres terminal associées.
2. Décompresser le patch V2.4 dans le dossier racine de la V2.3.
3. Accepter le remplacement des fichiers.
4. Ne pas relancer `requirements.txt`.
5. Démarrer normalement avec `run_caduceus.bat`.

Les index Qdrant, métriques, audits et précédents utilisateur restent dans `%LOCALAPPDATA%\\CADUCEUS` sous Windows.
